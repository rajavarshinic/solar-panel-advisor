# ☀️ Solar Panel Placement Advisor (Colab Project)

This project helps identify the **best time and conditions** for optimal solar panel placement using historical **solar generation data**. It's built and run entirely in **Google Colab** using Python and data analysis libraries.

---

## 🔍 Objective

To analyze solar radiation and temperature data to:
- 📈 Visualize the relationship between temperature and irradiation
- 🕒 Recommend the best time of day for solar energy collection
- 📍 Consider geographic factors like latitude

---

## 📊 Dataset Used

- **Source:** [Kaggle - Solar Power Generation Data](https://www.kaggle.com/datasets/anikannal/solar-power-generation-data)
- **Features Used:**
  - `DATE_TIME`
  - `AMBIENT_TEMPERATURE`
  - `IRRADIATION`

---

## 🛠️ Tech Stack

- Python 3
- Google Colab
- Pandas, NumPy
- Matplotlib, Seaborn

---

## 🚀 How to Use

1. Open this notebook in Google Colab:  
   https://colab.research.google.com/drive/1Y-ziJeP4jTrJNf1jBsXelAU75S1KpEuJ?usp=sharing

2. Run all cells step by step.  
   The notebook will:
   - Load the dataset
   - Visualize solar radiation
   - Suggest the best time & conditions for solar panel setup

---

## 📌 Key Output

- Scatter plot: **Temperature vs Solar Irradiation**
- Line plot: **Irradiation across the day**
- Function output: Best time of day for solar panel use based on max irradiation
